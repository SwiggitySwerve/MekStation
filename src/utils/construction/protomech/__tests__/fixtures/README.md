# ProtoMech pinned-oracle fixtures

Each `*-java*.json` here is the output of an original-class probe (`*Probe.java`, same folder) run
against the pinned MegaMek build. The probe sources are committed so a fixture can be regenerated
and reviewed; nothing here is regenerated by a test.

## Re-running the movement probe

The probe needs a working directory that contains the pinned `mmconf/` (`UnitUtil` reads
`mmconf/milestoneReleases.yml` at class load) and a units directory that contains
`UnitVerifierOptions.xml`:

```
javac --release 21 -cp <MegaMek classpath> -d classes ProtoMekMovementProbe.java
java -cp <MegaMek classpath>;classes ProtoMekMovementProbe <unitsDir> <out.json> <list-of-blk-paths.txt>
```

`SHA-256(ProtoMekMovementProbe.java)` is recorded in the fixture's `meta.probeSha256`.
