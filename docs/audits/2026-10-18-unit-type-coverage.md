## Findings that change the priorities

1. **No MTF chassis/model identities are missing.** The **4,227 source files** represent **4,225 distinct chassis/model pairs**, all present in MekStation's **4,225 indexed definitions**. Two source identities occur twice. LAM, QuadVee, industrial, late-era and unofficial-rules designs were not excluded from this inventory. Data fidelity is the immediate mech problem. [C; M1]
2. **All 4,225 distinct mechs have a mismatched imported rules-level label.** Python uses zero-based numeric levels; MegaMek MTF uses 1–5. **555** experimental designs are labeled UNOFFICIAL; **16** level-5 designs default to STANDARD. Current `rulesLevel` cannot count actual unofficial exclusions. [C; M2]
3. **Six Ares OmniTripods are stored as bipeds.** All **180** industrial-structure designs and all Omni configurations are exposed as BattleMech. No shipped definition has a top-level Omni marker. The fresh converter would also collapse **10** QuadVee Omni configurations to Biped, although their committed JSONs correctly say QuadVee. Reproducibility must not freeze incorrect semantics. [C; M3]
4. **Non-mech implementation is ahead of data/discovery.** There are **6,684 BLK files**, but outside mechs the public unit tree has only **3 BA** and **3 infantry** examples. Both canonical services load only battlemechs. Several families have customizers/sheets; capitals have handlers without matching UI descriptors. [C; K; T; HN]
5. **Helper code is not complete unit support.** Vehicles and BA have concrete combat integration; aerospace/infantry/Proto high-level dispatchers have no production call sites found. State initialization and some movement/target hooks do exist. Saved custom combat explicitly requires a biped BattleMech. [G; A; CAM]

from pathlib import Path
from collections import Counter, defaultdict
import json, re, sys
s = Path.cwd()
d = Path('E:/Projects/Personal/mm-data/data/mekfiles')
sys.path.insert(0, str(s / 'scripts/megameklab-conversion'))
from mtf_parser import MTFParser
root = s / 'public/data/units/battlemechs'
index = json.loads((root / 'index.json').read_text())['units']
byname = {(u['chassis'], u['model']): u for u in index}
byid = {u['id']: u for u in index}
raw, motion, configs, rules = Counter(), Counter(), Counter(), Counter()
identities = defaultdict(list)
failures, missing, id_mismatch, config_errors, industrial = [], [], [], [], []
rule_errors, unofficial_paths = set(), []
def field(text, name):
    m = re.search(r'^' + name + r':(.*)$', text, re.I | re.M)
    return m.group(1).strip() if m else ''
for p in d.rglob('*'):
    if p.suffix.lower() == '.blk':
        text = p.read_text(errors='replace')
        def tag(name):
            m = re.search('<' + name + r'>\s*([^<\r\n]+)', text, re.I)
            return m.group(1).strip() if m else '?'
        kind = tag('UnitType')
        raw[kind] += 1
        motion[(kind, tag('motion_type').lower())] += 1
    elif p.suffix.lower() == '.mtf':
        text = p.read_text(encoding='utf-8')
        unit = MTFParser().parse_file(str(p))
        if unit is None:
            failures.append(str(p)); continue
        key = (unit.chassis, unit.model)
        identities[key].append(str(p.relative_to(d)))
        config = field(text, 'config')
        configs[config] += 1
        level = field(text, 'rules level')
        rules[level] += 1
        if 'unofficial' in [part.lower() for part in p.parts]:
            unofficial_paths.append(str(p))
        if key not in byname:
            missing.append(str(p)); continue
        row = byname[key]
        data = json.loads((root / row['path']).read_text())
        if unit.id not in byid:
            id_mismatch.append((str(p), unit.id, row['id']))
        desired = next((c for c in ('QuadVee','Tripod','LAM','Quad')
                        if c.lower() in config.lower()), 'Biped')
        if data['configuration'] != desired:
            config_errors.append((str(p), row['path'], desired))
        expected = {'1':'INTRODUCTORY','2':'STANDARD','3':'ADVANCED',
                    '4':'EXPERIMENTAL','5':'UNOFFICIAL'}.get(level)
        if row['rulesLevel'] != expected:
            rule_errors.add(key)
        if 'industrial' in field(text, 'structure').lower():
            industrial.append((key, data['unitType'], data['structure']['type']))
print('BLK:', sum(raw.values()), sorted(raw.items()))
print('MOTION:', sorted(motion.items()))
print('MTF/CONFIG:', sum(configs.values()), sorted(configs.items()))
print('IDENTITIES:', len(identities), 'INDEX:', len(index))
print('COLLISIONS:', {k:v for k,v in identities.items() if len(v)>1})
print('MISSING:', missing, 'FAILURES:', failures)
print('MISSING CHASSIS:', Counter(field(Path(p).read_text(), 'chassis') for p in missing))
print('ID MISMATCH:', id_mismatch)
print('RULES:', rules, 'WRONG UNIQUE LABELS:', len(rule_errors))
print('CONFIG ERRORS:', config_errors)
print('INDUSTRIAL:', len(industrial), Counter((a,b) for _,a,b in industrial))
print('UNOFFICIAL PATHS:', unofficial_paths)
print('PUBLIC JSON:', Counter(str(p.parent.relative_to(s/'public/data/units'))
      for p in (s/'public/data/units').rglob('*.json')))
print('ERAS:', Counter(u['path'].split('/')[0] for u in index))
print('YEARS:', min(u['year'] for u in index), max(u['year'] for u in index))
definitions = [json.loads((root/u['path']).read_text()) for u in index]
print('JSON TYPES:', Counter(u['unitType'] for u in definitions))
print('JSON OMNI FIELDS:', Counter(k for u in definitions for k in u if 'omni' in k.lower()))
