## What changed in the dated reconciliation

Equipment requirements now describe conservative ammo compatibility, independent Electronics filtering, actual Other grouping, dense responsive rows, and atomic placement with one undo. Record-sheet contracts describe the shared filled SVG, bounded 4x PNG rendering, Letter/A4 geometry, manual/fit zoom, staged render currentness, reserved printing, and recoverable PDF/print actions. Infantry reuses that viewer lifecycle.

Routing distinguishes seven visible BattleMech tabs from eight accepted identifiers and gives every explicit valid tab, including Structure, precedence over stored last-tab state. Omitted/invalid tabs retain existing restoration behavior. Armor styles, mobile controls, server SQLite library saves, browser drafts, and retained IndexedDB consumers are described at their actual boundaries.

Three new canonical capabilities cover BattleMech chassis identity, edit recovery, and immutable saved-custom-unit combat snapshots. Campaign requirements admit supported server-saved biped custom references through the ready catalog while retaining canonical-only fast-forward and blockers for unsupported/local/malformed references. Stale source paths, old annotations, and obsolete planning claims were cleaned up.
