# Recover native critical marker allocations

Native armor and structure cells are currently available in the editor and disappear on custom save. Materialize their exact source allocations through the existing load owner so they reserve capacity and survive cold reopen. Define the shared critical-entry recogniser for the later o3b, Celerity and PR-D extensions. Root approved the proposal at parity-3.2-o2-o3/o3/PROPOSAL.md; implementation is local only under the merge freeze.

Marker spellings and their per-name pin citations belong only to src/types/formats/mtf-component-vocabulary.json. No resolver precedence, mobility recovery, catalog data, BV arithmetic or serializer scanner change is included. Acceptance requires C3's coordinated round-trip census, zero of 42,814 frozen marker losses, unchanged other-owner cell sets, and production E2E proof.
