# Preserve vehicle turret source facts on current topology

## Why

Main already owns ordinary, superheavy, six-side, rotor and second-turret normalization, and owner ruling 5 has retired generic turret capacity. Independent Omni base-chassis allowances still need source-to-store transport, and genuinely unknown support equipment blocks still fall back to Body.

## What changes

- Specify a narrow allowance projection on top of current layout/normalization, preserving original documents and explicit absent/zero/negative raw facts.
- Specify constructor, persistence, duplication and normalized-definition transport for the existing source identities.
- Reject only genuinely unknown nonempty support blocks; retain all supported topology and empty blocks.
- Keep handler installed-empty integration as S14 work. Do not duplicate threshold tables, resolve equipment, change mass/BV formulas, edit catalogs or revive capacity.

## Capabilities

### New capabilities

- Combat vehicle turret source context and explicit unknown-support-block handling, within [vehicle-unit-system](../../specs/vehicle-unit-system/spec.md).

## Impact

Documentation only in this publication. S10 implements allowance/context and unknown-block boundaries in separate small slices; S14 completes any remaining handler installation wiring. No implementation or whole-unit parity is claimed here.
