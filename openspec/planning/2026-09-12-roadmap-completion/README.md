## Operating rules

Follow [DELIVERY.md](DELIVERY.md) for the per-PR lifecycle, review/check requirements, merge guards, evidence and cleanup. Follow [WORKERS.md](WORKERS.md) for Luna/Grok routing, file ownership and bounded parallelism. Effective capacity is three children with four total slots; use high/xhigh effort, no nested workers, and keep one parent integration leader.

Preserve the unrelated printable-model research, all existing audit/maintenance worktrees, user browser sessions, and immutable evidence. Worktree creation and removal must have recorded absolute path/identity/HEAD ownership. No blanket deletion, forced cleanup, administrative check bypass, fabricated approval, broad dependency upgrade, or rights-unverified model acquisition belongs to this roadmap.
